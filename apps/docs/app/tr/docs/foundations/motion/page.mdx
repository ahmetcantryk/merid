# Hareket

Merid'de hareket sakin ve kısadır. Bir şeyin olduğunu doğrular, izlenmeyi hiçbir zaman beklemez. Tüm geçişler hızlı başlayıp sekmeden yerine oturan tek bir eğri kullanır.

## Token'lar

<MotionTable locale="tr" />

Giriş animasyonları 180ms'lik bir fade kullanır: eleman 4px yükselerek yerine otururken opaklık 0'dan 1'e çıkar. Overlay'ler yalnızca dikey yönde hareket eder.

## Desenler

- **Hover** arka planı renklendirir. Etkileşimli kartlar ayrıca 3px yükselir.
- **Basma** kontrolü 80ms içinde 1px aşağı indirir (`--mrd-press`), sanki sayfaya bastırılmış gibi. Hiçbir şey küçülmez.
- **Açılma** fade ile belirir ve yükselir; overlay'ler arka plan örtüsünü aynı anda fade ile getirir.
- **Dönme** yalnızca açılır-kapanır ikonlar içindir; örneğin accordion'daki artı işaretinin 45° dönmesi.

## Azaltılmış hareket

Kullanıcı azaltılmış hareket istediğinde Merid, skeleton shimmer dahil tüm geçiş ve animasyonları tamamen kaldırır. State yine anında değişir, yani hiçbir şey kaybolmaz.

```css
@media (prefers-reduced-motion: reduce) {
  .your-component {
    transition: none;
  }
}
```

Merid'in base layer'ı bunu `.mrd-root` içindeki her şeye uygular; her component de azaltılmış harekette kendi hareketini bırakır.
