# Boşluk

Boşluklar 4px'lik bir taban ve 8px'lik bir ritim üzerine kurulur. Ölçek bazı adımları bilerek atlar: daha az seçenek, daha tutarlı layout demektir.

## Kurallar

- Ferahlığı tercih et. Bölümler çizgi ya da kutuyla değil, cömert padding'le ayrılır.
- Bir component'in içindeki boşluk, component'ler arasındaki boşluktan küçüktür.
- Kart padding'i `--mrd-space-5` (20px), dialog padding'i `--mrd-space-6` (24px).
- Flex ve grid container'larında child'lara margin vermek yerine `gap` kullan.
