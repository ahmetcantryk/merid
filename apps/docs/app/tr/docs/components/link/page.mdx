# Link

Navigasyon için stillenmiş bir `<a>`: metnin içinde ya da listelerde ve footer'larda tek başına. Sonuç yeni bir yere gitmek değil de bir aksiyonsa [Button](/tr/docs/components/button) kullan.

## Import

```tsx
import { Link } from "@meridui/react";
```

## Örnekler

### Tonlar

`accent` (varsayılan) akan metnin içindeki linkler içindir. `ink` ve `muted` daha sakindir; her öğenin link olduğu navigasyon listeleri ve footer'lar için uygundur.

<ComponentPreview code={`<Link href="#" tone="accent">Accent</Link>
<Link href="#" tone="ink">Ink</Link>
<Link href="#" tone="muted">Muted</Link>`}>
  <LinkTones />
</ComponentPreview>

### Alt çizgi

`hover` (varsayılan) alt çizgiyi hover ve focus'ta gösterir. Link renkten bağımsız olarak da ayırt edilebilmeliyse `always` kullan, örneğin muted renkli bir paragrafın içinde.

<ComponentPreview code={`<Link href="#" underline="hover">Hover'da altı çizili</Link>
<Link href="#" underline="always">Her zaman altı çizili</Link>
<Link href="#" underline="none">Alt çizgi yok</Link>`}>
  <LinkUnderlines />
</ComponentPreview>

### Harici link

`external` linki yeni bir tab'da açar, `rel="noopener noreferrer"` ekler ve ekran okuyucu kullanıcıları uyarılsın diye görsel olarak gizli bir “(opens in a new tab)” metni ekler.

<Callout tone="warning">
  Bu gizli metin varsayılan olarak İngilizcedir (“(opens in a new tab)”). Türkçe arayüzde `externalLabel` ile Türkçe ver; yoksa ekran okuyucular uyarıyı İngilizce okur.
</Callout>

<ComponentPreview code={`<Link href="https://github.com/ahmetcantryk/merid" external externalLabel="(yeni sekmede açılır)">
  GitHub reposu
</Link>`}>
  <LinkExternal />
</ComponentPreview>

### Client-side router ile

`asChild` ver ve router'ının link component'ini tek child olarak geçir: Merid'in link stilini alır, kendi davranışını korur. Bu server component'lerde de çalışır.

```tsx
import NextLink from "next/link";

<Link asChild tone="accent">
  <NextLink href="/pricing">Fiyatlandırma</NextLink>
</Link>
```

## Erişilebilirlik

- Native bir `<a>` render'lar: Enter linke gider ve link, ekran okuyucunun link listesinde görünür.
- Link metni bağlamından koparıldığında da anlamlı olmalı: “buraya tıkla” değil, “Fiyatlandırma rehberini oku”.
- `external` yeni tab uyarısını ekler; yeni tab'ları tek başına `target="_blank"` ile sessizce açma.
