# Switch

Değiştiği anda uygulanan ayarlar için 34×20'lik bir açık/kapalı anahtarı. Bir checkbox değil, `<button role="switch">`'tir.

## Import

```tsx
import { Switch } from "@meridui/react";
```

## Örnekler

### Controlled

`defaultChecked` state'i switch'in içinde tutar. Controlled kullanım için `checked` ve bir sonraki boolean değeri alan `onCheckedChange` ver.

<ComponentPreview code={`const [on, setOn] = useState(false);

<Switch checked={on} onCheckedChange={setOn}>
  Taslakları otomatik kaydet
</Switch>`}>
  <SwitchControlled />
</ComponentPreview>

### Etiket konumu

<ComponentPreview code={`<Switch labelPosition="start">Etiket başta</Switch>
<Switch labelPosition="end">Etiket sonda</Switch>`}>
  <SwitchLabelPosition />
</ComponentPreview>

### Devre dışı ve etiketsiz

Children vermiyorsan switch'e bir `aria-label` ver.

<ComponentPreview code={`<Switch disabled>Devre dışı, kapalı</Switch>
<Switch disabled defaultChecked>Devre dışı, açık</Switch>
<Switch aria-label="Bildirimler" />`}>
  <SwitchStates />
</ComponentPreview>

### Form içinde

Bir buton kendi başına değer göndermez. `name` verirsen switch gizli bir input render'lar; bu input switch açıkken `value` değerini gönderir (varsayılanı `"on"`). Kapalıyken hiçbir şey gönderilmez.

<ComponentPreview code={`<form>
  <Switch name="newsletter" value="yes" defaultChecked>
    Bültene abone ol
  </Switch>
</form>`}>
  <SwitchForm />
</ComponentPreview>

## Erişilebilirlik

- `aria-checked` ile birlikte `role="switch"` olarak sunulur, ekran okuyucular “açık” / “kapalı” diye okur.
- Görünür etiket `aria-labelledby` ile bağlanır; etikete tıklamak da switch'i değiştirir.
- Bir `Field` içinde switch, Field'ın id'sini alır (böylece adını Field etiketinden alır); `aria-describedby`, `aria-invalid` ve `disabled` değerlerini de ondan alır.
- Geçersizlik anlamını `aria-invalid` taşır; stili `data-invalid` belirler.
