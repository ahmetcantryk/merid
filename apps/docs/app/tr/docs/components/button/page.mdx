# Button

Bir aksiyonu tetikler: form göndermek, dialog açmak, bir değişikliği kaydetmek. Sonuç başka bir sayfaya gitmekse buton yerine link kullan.

## Import

```tsx
import { Button } from "@meridui/react";
```

## Örnekler

### Varyantlar

`primary`, ekrandaki tek accent aksiyondur. `secondary` (varsayılan) geri kalan her şey içindir; `ghost` toolbar'larda ve yoğun satırlarda sessizce durur; `danger` geri alınamayan aksiyonları onaylar; `link` satır içi metin gibi görünür ama buton semantiğini korur.

<ComponentPreview code={`<Button variant="primary">Primary</Button>
<Button variant="secondary">Secondary</Button>
<Button variant="ghost">Ghost</Button>
<Button variant="danger">Danger</Button>
<Button variant="link">Link</Button>`}>
  <ButtonVariants />
</ComponentPreview>

### Boyutlar

`sm` 36px, `md` 44px (varsayılan), `lg` 50px yüksekliğindedir. Yan yana duran kontroller aynı taban çizgisini paylaşsın diye boyutu komşu input'larla eşleştir.

<ComponentPreview code={`<Button size="sm">Küçük</Button>
<Button size="md">Orta</Button>
<Button size="lg">Büyük</Button>`}>
  <ButtonSizes />
</ComponentPreview>

### İkonlu

`leadingIcon` ve `trailingIcon` herhangi bir node alır. İkisi de `aria-hidden` span'lere sarılır; butonun adını yalnızca etiket belirler.

<ComponentPreview code={`<Button variant="primary" leadingIcon={<PlusIcon />}>Yeni proje</Button>
<Button trailingIcon={<ArrowRightIcon />}>Devam et</Button>
<Button variant="danger" leadingIcon={<TrashIcon />}>Sil</Button>`}>
  <ButtonIcons />
</ComponentPreview>

### Yükleniyor

`loading` butonun üstüne bir spinner koyar, layout zıplamasın diye genişliği korur, `aria-busy` ve `aria-disabled` atar ve tıklamaları yutar. Buton focus alabilir kalır, yani istek sürerken klavye focus'u kaybolmaz.

<ComponentPreview code={`const [saving, setSaving] = useState(false);

<Button
  variant="primary"
  loading={saving}
  onClick={() => {
    setSaving(true);
    window.setTimeout(() => setSaving(false), 1500);
  }}
>
  Değişiklikleri kaydet
</Button>`}>
  <ButtonLoading />
</ComponentPreview>

### Devre dışı

`disabled` native attribute'tur: buton tab sırasından çıkar ve tıklamaları yok sayar. Bir aksiyonu sessizce devre dışı bırakmak yerine neden kullanılamadığını açıklamayı tercih et.

<ComponentPreview code={`<Button variant="primary" disabled>Yayınla</Button>
<Button disabled>Dışa aktar</Button>`}>
  <ButtonDisabled />
</ComponentPreview>

### Tam genişlik

`fullWidth` butonu container'ı boyunca uzatır. Dar formlarda ve mobilde işe yarar.

<ComponentPreview code={`<Button variant="primary" fullWidth>Hesap oluştur</Button>`}>
  <ButtonFullWidth />
</ComponentPreview>

### Router link'i olarak

Router'ının link'ini buton görünümüyle render'lamak için `asChild` kullan. Böylece navigasyon gerçek bir link olarak kalır:

```tsx
import Link from "next/link";

<Button asChild variant="primary">
  <Link href="/signup">Ücretsiz başla</Link>
</Button>
```

## Erişilebilirlik

- Native bir `<button>` render'lar; Enter ve Space ile tetiklenir, formlara katılır.
- Görünen etiket, butonun erişilebilir adıdır. Yalnızca ikondan oluşan aksiyonlar için `label`'ı zorunlu olan [IconButton](/tr/docs/components/icon-button)'ı kullan.
- `loading` sırasında buton `aria-busy="true"` ve `aria-disabled="true"` bildirir ama focus'u korur.
