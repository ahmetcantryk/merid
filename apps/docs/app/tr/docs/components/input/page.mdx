# Input

Tek satırlık bir metin input'u. Bir [Field](/tr/docs/components/field) içinde id'sini, açıklamasını, hatasını ve zorunluluk state'ini otomatik olarak alır.

## Import

```tsx
import { Input } from "@merid/react";
```

## Örnekler

### Boyutlar

`sm` 36px, `md` 46px (varsayılan), `lg` 50px.

<ComponentPreview code={`<Input size="sm" placeholder="Küçük, 36px" />
<Input size="md" placeholder="Orta, 46px" />
<Input size="lg" placeholder="Büyük, 50px" />`}>
  <InputSizes />
</ComponentPreview>

### Baş ve son ekler

`leading` ve `trailing`, çerçevenin içine dekoratif ikonlar, önekler ya da birimler ekler. Bunlar `aria-hidden`'dır; anlamlı olan her şeyi (örneğin para birimini) etikette de belirt. İkisinden biri verildiğinde input `.mrd-input-group` ile sarılır ve `className` bu sarmalayıcıya geçer.

<ComponentPreview code={`<Input aria-label="Ara" leading={<SearchIcon />} placeholder="Projelerde ara" />
<Input aria-label="Tutar" type="number" trailing="TRY" defaultValue="250" />`}>
  <InputAddons />
</ComponentPreview>

### Geçersiz, devre dışı, salt okunur

`invalid`, geçersiz stilini ve `aria-invalid`'i zorlar; Field içinde Field'ın `error`'unu izler. `disabled` ve `readOnly` native attribute'lardır.

<ComponentPreview code={`<Input aria-label="Geçersiz" invalid defaultValue="e-posta-degil" />
<Input aria-label="Devre dışı" disabled defaultValue="Devre dışı" />
<Input aria-label="Salt okunur" readOnly defaultValue="Salt okunur" />`}>
  <InputStates />
</ComponentPreview>

### Controlled

Input sade bir `<input>`'tur: kontrol etmek için `value` + `onChange`, uncontrolled bırakmak için `defaultValue` kullan.

<ComponentPreview code={`const [value, setValue] = useState("");

<Input
  aria-label="Çalışma alanı URL'si"
  value={value}
  onChange={(event) => setValue(event.target.value)}
  placeholder="acme"
/>
<Text size="xs" tone="muted">meridui.dev/{value || "…"}</Text>`}>
  <InputControlled />
</ComponentPreview>

## API referansı

`Input` ref'ini `<input>`'a iletir ve diğer tüm native input attribute'larını olduğu gibi geçirir. `className` ve `style` her zaman kök elemana gider: `<input>`'un kendisine ya da `leading` veya `trailing` verildiğinde `.mrd-input-group` sarmalayıcısına. `type` varsayılan olarak `"text"`'tir.

## Erişilebilirlik

- Her input'un bir adı olmalı: görünür bir [Label](/tr/docs/components/label) / [Field](/tr/docs/components/field) ya da amacı bağlamdan belli olduğunda (arama gibi) `aria-label`.
- Placeholder bir etiket değildir; yazmaya başlayınca kaybolur ve kontrastı düşüktür.
