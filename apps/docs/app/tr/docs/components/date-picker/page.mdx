# DatePicker

Yazılabilen bir tarih alanı; yanındaki buton [Calendar](/tr/docs/components/calendar)'ı bir popover içinde açar. Yazılan metin locale'in sayısal sırasıyla (`tr-TR` için `30.09.2026`, `en-US` için `09/30/2026`) ya da ISO biçiminde (`2026-09-30`) okunur.

<Callout tone="success">
  `locale` varsayılan olarak `"en-US"`dir ve placeholder bu yüzden `MM/DD/YYYY` olur. Takvim butonu ve dialog'u “Choose date”, ay butonları “Previous month” / “Next month”, aralık alanları “Start date” / “End date” adını alır. Türkçe arayüzde `locale="tr-TR"`, `placeholder="GG.AA.YYYY"`, `calendarLabel`, `previousMonthLabel`, `nextMonthLabel` ve aralıkta `startLabel` / `endLabel` ver.
</Callout>

## Import

```tsx
import { DatePicker } from "@meridui/react";
```

## Örnekler

### Aralık

`mode="range"` bir başlangıç ve bir bitiş alanı render'lar. İki gün de seçilince takvim kapanır.

<ComponentPreview code={`const [range, setRange] = useState<DateRange>({ start: null, end: null });

<DatePicker
  locale="tr-TR"
  mode="range"
  value={range}
  onValueChange={setRange}
  startLabel="Giriş tarihi"
  endLabel="Çıkış tarihi"
/>`}>
  <DatePickerRange />
</ComponentPreview>

### En erken, en geç ve devre dışı günler

Sınırların dışında yazılan tarihler reddedilir ve alan son geçerli değere döner.

<ComponentPreview code={`<DatePicker locale="tr-TR" min={today} isDateDisabled={(d) => d.getDay() === 0 || d.getDay() === 6} />`}>
  <DatePickerConstraints />
</ComponentPreview>

### Boyutlar ve durumlar

<ComponentPreview code={`<DatePicker aria-label="Küçük" size="sm" />
<DatePicker aria-label="Geçersiz" invalid />
<DatePicker aria-label="Devre dışı" disabled defaultValue={today} />`}>
  <DatePickerStates />
</ComponentPreview>

### Formda

`name` verildiğinde gizli bir input `yyyy-mm-dd` gönderir. Aralık iki değeri `name[]` altında gönderir. `toISODate(date)` aynı string'i verir.

## Stil verme

| Sınıf | Eleman |
|---|---|
| `.mrd-date-picker` | Kök (`data-size`, `data-mode`, `data-invalid`, `data-disabled`) |
| `.mrd-date-picker__field` | Kenarlıklı alan |
| `.mrd-date-picker__input`, `.mrd-date-picker__separator` | Metin alan(lar)ı ve aralık tiresi |
| `.mrd-date-picker__trigger` | Takvim butonu (`data-state`) |
| `.mrd-date-picker__content` | Takvimi tutan popover |

## Erişilebilirlik

Asıl girdi metin alanıdır; takvim butonu (`aria-haspopup="dialog"`) seçili güne focus veren, modal olmayan bir dialog açar. Gün seçmek ya da Escape dialog'u kapatır ve focus'u butona döndürür. Grid içindeki tuşlar için [Calendar](/tr/docs/components/calendar#erisilebilirlik) sayfasına bak.
