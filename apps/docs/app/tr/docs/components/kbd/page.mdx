# Kbd

Metinde, menülerde ve tooltip'lerde klavye kısayollarını göstermek için bir tuş başlığı. Semantik bir `<kbd>` render'lar.

## Import

```tsx
import { Kbd } from "@merid/react";
```

## Örnekler

### Boyutlar

`md` (varsayılan) gövde metninde durur; `sm` menü öğelerine, tooltip'lere ve yoğun satırlara sığar.

<ComponentPreview code={`<Kbd size="sm">Esc</Kbd>
<Kbd size="md">Esc</Kbd>`}>
  <KbdSizes />
</ComponentPreview>

### Tuş kombinasyonları

Her tuş için bir `Kbd` render'la, ayracı aralarına düz metin olarak koy.

<ComponentPreview code={`<Kbd>Ctrl</Kbd> + <Kbd>Shift</Kbd> + <Kbd>P</Kbd>`}>
  <KbdChord />
</ComponentPreview>

## Erişilebilirlik

- `<kbd>` metni olarak okunur. Ekran okuyucuların kötü seslendirdiği sembolleri yazıyla ver: “⌃” yerine “Ctrl”i tercih et ya da glifin yanına bir [VisuallyHidden](/tr/docs/components/visually-hidden) ad ekle.
- Kbd etkileşimli değildir; bir kısayolu belgeler, onu bağlamaz.
