# Textarea

Yorum, açıklama ve mesajlar için çok satırlı bir metin girişi. Bir [Field](/tr/docs/components/field) içinde kullanıldığında id'sini, açıklamasını, hatasını ve zorunlu state'ini oradan alır.

## Import

```tsx
import { Textarea } from "@meridui/react";
```

## Örnekler

### Boyutlandırma

Boyutlandırma tutamacı varsayılan olarak `vertical`'dır. Layout'un değişmemesi gerekiyorsa `none` kullan, `both`'u ise nadiren.

<ComponentPreview code={`<Textarea rows={2} placeholder="resize vertical (varsayılan)" />
<Textarea rows={2} resize="none" placeholder="resize none" />
<Textarea rows={2} resize="both" placeholder="resize both" />`}>
  <TextareaResize />
</ComponentPreview>

### Geçersiz ve devre dışı

<ComponentPreview code={`<Textarea rows={2} invalid defaultValue="Çok kısa" />
<Textarea rows={2} disabled defaultValue="Devre dışı" />`}>
  <TextareaStates />
</ComponentPreview>

### Sayaçlı controlled kullanım

<ComponentPreview code={`const [value, setValue] = useState("");

<Textarea
  aria-label="Durum"
  value={value}
  maxLength={140}
  onChange={(event) => setValue(event.target.value)}

<Text size="xs" tone="muted" numeric>{value.length} / 140</Text>`}>
