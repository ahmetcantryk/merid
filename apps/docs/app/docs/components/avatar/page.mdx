# Avatar

A circular image, or initials on a tray fill, that stands for a person or organisation. `AvatarGroup` stacks several with an overflow count.

### Image and fallback

Pass `src` for a photo. When it is missing or fails to load, the avatar falls back to initials derived from `name` — the first letter of the first and last word. `initials` overrides them (at most two characters are shown).

<ComponentPreview code={`<Avatar name="Broken Image" src="/does-not-exist.png" />
<Avatar name="Acme Corporation" initials="AC" />`}>
  <AvatarFallback />
</ComponentPreview>

### Group

`max` limits the visible avatars; the rest collapse into a “+N” chip. Set the group's `size` to match its avatars so the chip lines up.

<ComponentPreview code={`<AvatarGroup aria-label="Project members" max={3} size="sm">

## API reference

### Avatar

Renders a `span`; the ref and other span attributes are forwarded.

<PropsTable rows={[
  { name: "name", type: "string", required: true, description: "Person or entity name. The accessible name and the source of initials." },
  { name: "src", type: "string", description: "Image URL. Falls back to initials when missing or when loading fails." },
  { name: "size", type: '"xs" | "sm" | "md" | "lg" | "xl"', default: '"md"', description: "Diameter: 24, 32, 40, 48 or 64px." },
  { name: "initials", type: "string", description: "Overrides the derived initials (max 2 characters shown)." },
]} />

### AvatarGroup

Renders a `div` with `role="group"`.

<PropsTable rows={[
  { name: "max", type: "number", description: "Maximum avatars shown; the rest collapse into a +N chip." },
  { name: "size", type: '"xs" | "sm" | "md" | "lg" | "xl"', default: '"md"', description: "Size of the overflow chip; match the avatars' size." },
  { name: "children", type: "ReactNode", description: "Avatar elements." },
]} />

### getInitials

`getInitials(name: string): string` returns up to two upper-case initials — `getInitials("Ada Lovelace")` is `"AL"`, `getInitials("Linus")` is `"L"`.

## Accessibility

- Each avatar is `role="img"` named by `name`; the inner image has `alt=""` and the initials are hidden, so the name is read once.
- The overflow chip is announced as “N more”.
- Name the group with `aria-label` (“Project members”) so the list has context.
- When an avatar sits next to the person's visible name, the name is read twice; pass `aria-hidden` on the avatar in that case.
