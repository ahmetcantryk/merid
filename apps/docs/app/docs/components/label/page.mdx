# Label

A form label: 14px, weight 500, ink. Use it directly when you wire a control yourself; [Field](/docs/components/field) renders one for you.

## Import

```tsx
import { Label } from "@merid/react";
```

## Examples

### Required

`required` appends an `*` that is hidden from assistive tech. It is only a visual cue — set `required` on the control too so it is announced and validated.

<ComponentPreview code={`<Label htmlFor="name" required>Full name</Label>
<Input id="name" required />`}>
  <LabelRequired />
</ComponentPreview>

### Disabled

`disabled` dims the label to match a disabled control. It does not disable anything by itself.

<ComponentPreview code={`<Label htmlFor="workspace" disabled>Workspace</Label>
<Input id="workspace" defaultValue="acme" disabled />`}>
  <LabelDisabled />
</ComponentPreview>

## API reference

`Label` forwards its ref to the `<label>` and passes other label attributes (`htmlFor`, `id`, …) through.

## Accessibility

- Always connect the label with `htmlFor` matching the control's `id`; clicking the label then focuses the control and it becomes its accessible name.
- The `*` is `aria-hidden`; “required” is announced from the control's own `required` attribute.
