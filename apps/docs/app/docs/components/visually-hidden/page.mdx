# VisuallyHidden

Hides content from sight while keeping it in the accessibility tree. Use it for context that is obvious visually but not when read aloud.

## Accessibility

- Content stays readable by screen readers and in the tab order if focusable. Do not hide focusable elements — a sighted keyboard user would focus something invisible.
- For icon-only buttons, prefer [IconButton](/docs/components/icon-button)'s `label`, which sets `aria-label` directly.
