# Spacing

Spacing is built on a 4px base with an 8px rhythm. The scale skips steps on purpose: fewer choices make layouts more consistent.

## Rules

- Prefer air. Sections are separated by generous padding, not by rules or boxes.
- Space inside a component is smaller than the space between components.
- Card padding is `--mrd-space-7` (28px); dialog padding is `--mrd-space-8` (32px).
- Use `gap` on flex and grid containers rather than margins on children.
