# Logo and usage

The Merid mark is a hairline circle crossed by a single accent meridian: a thin, precise reference line through a whole. It is drawn with the same 1.5px stroke weight as the library's icons and pairs with a lowercase wordmark set in Inter at 600 with tight tracking.

## Clear space

Keep clear space around the logo equal to the radius of the circle in the mark — half its height. Nothing else, including other logos and the edge of the frame, should enter that space.

## Minimum size

The full logo should be at least 80px wide on screen. Below that, use the mark alone at 16px or larger.

## Colour

Use the light version on white or `--mrd-tray`, and the dark version on `--mrd-bg` in dark mode. When colour is unavailable — engraving, single-colour print, a monochrome badge — use the mono version. The accent in the mark is always `#3f63f5` in light and `#6b8aff` in dark.

## Name

Write the name as **Merid** in running text, with a capital M. The wordmark is lowercase by design. The package is `@merid/react`.
