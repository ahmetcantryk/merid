# Progress

A linear bar that shows how far a task has got — an upload, an export, an onboarding checklist. Without a value it becomes an indeterminate loading bar.

## Examples

### Sizes

`sm` 4px, `md` 6px (default), `lg` 8px thick.

<ComponentPreview code={`<Progress aria-label="Small" size="sm" value={40} />
<Progress aria-label="Medium" size="md" value={60} />
<Progress aria-label="Large" size="lg" value={80} />`}>
  <ProgressSizes />
</ComponentPreview>

### Indeterminate

Omit `value` (or pass `null`) when the duration is unknown.

<ComponentPreview code={`<Progress aria-label="Preparing export" />`}>
  <ProgressIndeterminate />
</ComponentPreview>

### Custom max and value text

`max` changes the scale; `valueText` replaces the default percentage that screen readers announce.

<ComponentPreview code={`<Progress aria-label="Onboarding" value={3} max={5} valueText="3 of 5 steps" />`}>
  <ProgressValueText />
</ComponentPreview>

### Updating

Values are clamped between 0 and `max`. The bar reaches `data-state="complete"` at 100%.

<ComponentPreview code={`const [value, setValue] = useState(0);
// update value as work completes

<Progress aria-label="Syncing" value={value} />`}>
  <ProgressLive />
</ComponentPreview>

## API reference

Renders a `div` with `role="progressbar"`; the ref and other div attributes are forwarded.

## Accessibility

- `role="progressbar"` with `aria-valuemin`, `aria-valuemax`, `aria-valuenow` and `aria-valuetext`. In the indeterminate state no `aria-value*` attribute is set.
- Always name the bar with `aria-label` or `aria-labelledby` — the element has no text of its own.
- Under `prefers-reduced-motion` the indeterminate animation is removed.
