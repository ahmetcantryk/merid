# Link

A styled `<a>` for navigation — inline in text or standalone in lists and footers. Use a [Button](/docs/components/button) when the result is an action rather than a new location.

## Import

```tsx
import { Link } from "@meridui/react";
```

## Examples

### Tones

`accent` (default) is for links inside running text. `ink` and `muted` are quieter, for navigation lists and footers where every item is a link.

<ComponentPreview code={`<Link href="#" tone="accent">Accent</Link>
<Link href="#" tone="ink">Ink</Link>
<Link href="#" tone="muted">Muted</Link>`}>
  <LinkTones />
</ComponentPreview>

### Underline

`hover` (default) shows the underline on hover and focus. Use `always` when the link must be distinguishable without colour — for example inside a paragraph of muted text.

<ComponentPreview code={`<Link href="#" underline="hover">Underline on hover</Link>
<Link href="#" underline="always">Always underlined</Link>
<Link href="#" underline="none">No underline</Link>`}>
  <LinkUnderlines />
</ComponentPreview>

### External

`external` opens the link in a new tab, sets `rel="noopener noreferrer"`, and appends a visually hidden “(opens in a new tab)” so screen reader users are warned.

<ComponentPreview code={`<Link href="https://github.com/ahmetcantryk/merid" external>
  GitHub repository
</Link>`}>
  <LinkExternal />
</ComponentPreview>

### With a client-side router

Pass `asChild` and your router's link as the only child: it gets Merid's link styling and keeps its own behaviour. This also works from server components.

```tsx
import NextLink from "next/link";

<Link asChild tone="accent">
  <NextLink href="/pricing">Pricing</NextLink>
</Link>
```

## API reference

Forwards its ref to the `<a>` and passes all native anchor attributes through. When `external` is set, it overrides `target` and `rel`.

## Accessibility

- Renders a native `<a>`: Enter follows it, and it appears in the screen reader's links list.
- Link text must make sense out of context — “Read the pricing guide”, not “click here”.
- `external` adds the new-tab warning; do not open new tabs silently with `target="_blank"` alone.
