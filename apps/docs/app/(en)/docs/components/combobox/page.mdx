## Import

```tsx
import { Combobox, type ComboboxOption } from "@meridui/react";
```

## Examples

### Multiple

`multiple` keeps the list open after each pick and shows the selection as chips. `value` becomes a `string[]`. Backspace in an empty field removes the last chip.

<ComponentPreview code={`const [value, setValue] = useState<string[]>(["next", "vite"]);

<Field label="Stack" description="Pick any number.">
  <Combobox multiple options={frameworks} value={value} onValueChange={setValue} placeholder="Add…" />
</Field>`}>
  <ComboboxMultiple />
</ComponentPreview>

### Async options

Fetch from `onInputValueChange`, pass the results as `options`, set `filter={false}` so the component does not filter again, and toggle `loading` while the request runs. Labels of chosen options are remembered, so chips and the field keep their text when the results change.

<ComponentPreview code={`const [text, setText] = useState("");
const [options, setOptions] = useState<ComboboxOption[]>([]);
const [loading, setLoading] = useState(false);

useEffect(() => {
  if (!text.trim()) return;
  setLoading(true);
  const timer = setTimeout(async () => {
    setOptions(await searchCities(text));
    setLoading(false);
  }, 200);
  return () => clearTimeout(timer);
}, [text]);

<Combobox
  options={options}
  filter={false}
  loading={loading}
  onInputValueChange={setText}
  emptyMessage="No cities found"
/>`}>
  <ComboboxAsync />
</ComponentPreview>

## Accessibility

Follows the WAI-ARIA [Combobox pattern with a listbox popup](https://www.w3.org/WAI/ARIA/apg/patterns/combobox/) and list autocomplete. Focus stays in the text field; the highlighted option is exposed with `aria-activedescendant`. The loading and empty messages are a `role="status"` region, so they are announced. Chip remove buttons are skipped by Tab; use Backspace in the empty field, or the pointer.
