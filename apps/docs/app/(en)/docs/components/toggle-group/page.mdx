# ToggleGroup

Two-state buttons (`aria-pressed`). Use `Toggle` for one option that stays on, and `ToggleGroup` for a set: `type="single"` is a deselectable choice, `type="multiple"` independent toggles.

## Styling

| Class | Element |
|---|---|
| `.mrd-toggle` | Toggle and every group item (`data-state="on" \| "off"`, `data-size`) |
| `.mrd-toggle-group` | Group (`data-orientation`) |
| `.mrd-toggle-group__item` | Group item |

## Accessibility

Every item is a `<button aria-pressed>`, so screen readers announce "pressed" / "not pressed". The group is one tab stop (roving `tabindex`); arrow keys move focus without changing the state, Space or Enter toggles. Icon-only items need an `aria-label`.
