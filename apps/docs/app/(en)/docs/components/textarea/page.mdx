# Textarea

A multi-line text input for comments, descriptions and messages. Inside a [Field](/docs/components/field) it picks up its id, description, error and required state.

## Examples

### Resize

The handle defaults to `vertical`. Use `none` when the layout must not change, `both` rarely.

## API reference

`Textarea` forwards its ref to the `<textarea>` and passes every other native attribute through.

## Accessibility

- Give it a visible label through [Field](/docs/components/field) or [Label](/docs/components/label).
- If you show a character counter, keep `maxLength` and the visible count in sync; consider linking the counter with `aria-describedby`.
