# EmptyState

A centred placeholder for the moments when there is nothing to show: an empty list, a search with no results, a first-run screen. It explains why and offers the next step.

## Import

```tsx
import { EmptyState } from "@meridui/react";
```

## Examples

### Plain

`variant="plain"` drops the tray background — use it inside a card or table frame that already has a surface. `titleLevel` sets the heading level to fit the page outline.

<ComponentPreview code={`<EmptyState
  variant="plain"
  icon={<SearchIcon />}
  title="No results for “quarterly”"
  description="Try a shorter search or check the spelling."
  action={<Button>Clear search</Button>}
  titleLevel={2}
/>`}>
  <EmptyStatePlain />
</ComponentPreview>

## Accessibility

- The title is a real heading (`h3` by default); set `titleLevel` so it fits the surrounding outline.
- The icon is `aria-hidden`; the title must carry the meaning on its own.
- When the empty state replaces results after a search, announce the change — for example render the result count in a polite live region.
