# DatePicker

A date field you can type into, with a [Calendar](/docs/components/calendar) in a popover. Typed text is read in the locale's numeric order (`09/30/2026` for `en-US`, `30.09.2026` for `tr-TR`) or as ISO `2026-09-30`.

```tsx

```

## Examples

### Range

`mode="range"` renders a start and an end field. The calendar closes once both days are picked.

<ComponentPreview code={`const [range, setRange] = useState<DateRange>({ start: null, end: null });

<DatePicker mode="range" value={range} onValueChange={setRange} startLabel="Check-in" endLabel="Check-out" />`}>
  <DatePickerRange />
</ComponentPreview>

### Min, max and disabled days

Typed dates outside the limits are rejected and the field reverts to the last valid value.

<ComponentPreview code={`<DatePicker min={today} isDateDisabled={(d) => d.getDay() === 0 || d.getDay() === 6} />`}>
  <DatePickerConstraints />
</ComponentPreview>

### Sizes and states

<ComponentPreview code={`<DatePicker aria-label="Small" size="sm" />
<DatePicker aria-label="Invalid" invalid />
<DatePicker aria-label="Disabled" disabled defaultValue={today} />`}>
  <DatePickerStates />
</ComponentPreview>

### In a form

With `name`, a hidden input submits `yyyy-mm-dd`. A range submits two values under `name[]`. `toISODate(date)` gives the same string.

## Accessibility

The text field is the primary input; the calendar button (`aria-haspopup="dialog"`) opens a non-modal dialog with focus on the selected day. Picking a day or pressing Escape closes it and returns focus to the button. See [Calendar](/docs/components/calendar#accessibility) for keys inside the grid.
