# PinInput

One-time code and PIN entry with one cell per character. Typing moves forward, Backspace moves back, and pasting or SMS autofill fills every cell.

## API reference

Renders a `div role="group"`; name it with `aria-label`, `aria-labelledby` or a [Field](/docs/components/field). The ref goes to the group.

## Accessibility

Each cell is a labelled text input ("Character 1 of 6") inside a named group, and the first cell has `autocomplete="one-time-code"` so browsers can offer the SMS code. Codes never contain gaps: typing past the end of the code writes into the first empty cell.
