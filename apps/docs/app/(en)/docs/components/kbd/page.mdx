# Kbd

A key cap for showing keyboard shortcuts in text, menus and tooltips. Renders a semantic `<kbd>`.

## Import

```tsx
import { Kbd } from "@merid/react";
```

## Examples

### Sizes

`md` (default) sits in body text; `sm` fits inside menu items, tooltips and dense rows.

<ComponentPreview code={`<Kbd size="sm">Esc</Kbd>
<Kbd size="md">Esc</Kbd>`}>
  <KbdSizes />
</ComponentPreview>

### Chords

Render one `Kbd` per key and put the separator between them as plain text.

## Accessibility

- `<kbd>` is read as its text. Spell out symbols that screen readers pronounce poorly — prefer “Ctrl” over “⌃”, or add a [VisuallyHidden](/docs/components/visually-hidden) name next to the glyph.
- Kbd is not interactive; it documents a shortcut, it does not bind one.
