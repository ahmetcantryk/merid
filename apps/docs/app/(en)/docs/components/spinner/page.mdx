# Spinner

An indeterminate loading indicator for short waits whose length is unknown. It inherits `currentColor`, so it matches whatever text or button it sits in.

```tsx
import { Spinner } from "@meridui/react";
```

## Examples

### Sizes

Diameters of 14px (`sm`), 18px (`md`, default) and 24px (`lg`).

### Next to text

When visible text already says what is loading, pass `label={null}` to hide the spinner from assistive tech so the message is not announced twice.

<ComponentPreview code={`<Stack direction="row" gap={2} align="center">

### Colour

Set `color` on the spinner or a parent. Give it a specific `label` when it stands alone.

## Accessibility

- With a label, the spinner has `role="status"` and `aria-label`, so screen readers announce it politely.
- With `label={null}` it is `aria-hidden`. Mark the region that is loading with `aria-busy="true"`.
- Under `prefers-reduced-motion`, the rotation slows down rather than stopping, so progress stays visible.
