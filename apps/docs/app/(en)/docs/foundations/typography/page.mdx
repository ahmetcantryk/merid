# Typography

Merid sets interface text and headings in **Archivo** and code in **Chivo Mono**. Both are variable fonts from Omnibus-Type, both are licensed under the SIL Open Font License, and both ship inside `@meridui/react`, so there is nothing to load from a font service. Numbers are tabular everywhere, so figures line up in tables and prices do not shift as they change.

## Why Archivo

Archivo has a real width axis. The same file draws a wide heading, the kind printed across the top of a map sheet, and an ordinary 14px label in a form. Merid uses that instead of pairing a display face with a text face, so headings and interface never look like they came from two different products. Its Turkish letters and the lira sign are drawn glyphs rather than accents stacked by the browser. Chivo Mono comes from the same foundry and shares its proportions, which keeps code samples from looking pasted in.

## Scale

Sizes are tokens: `--mrd-text-*` for the size, with matching `--mrd-leading-*` for line height and `--mrd-tracking-*` for letter spacing where it applies.

If you replace `--mrd-font-sans` with a family that has no width axis, these values have no effect and the browser uses the normal width.

## Weights

- **400** (`--mrd-weight-regular`): body text.
- **500** (`--mrd-weight-medium`): all interface text, from buttons and labels to navigation and tabs.
- **600** (`--mrd-weight-semibold`): headings and figures that need emphasis.

Weight 700 is never used, and the bundled files stop at 600, so a `<strong>` or a bold request renders at 600. When 600 is not enough contrast, change the tone instead.

## Capitals and Turkish

Merid adds no decorative small print: no eyebrows above headings and no mono captions. The only uppercase text in the library is the table column heading, at 12px with 0.04em tracking.

`text-transform: uppercase` follows the language of the element, and Merid never writes text of its own, so the result depends on your `lang` attribute. With `lang="tr"`, "Müşteri" becomes "MÜŞTERİ"; with `lang="en"` or no `lang` at all it becomes "MÜŞTERI", which a Turkish reader notices at once. Set `lang` on `<html>`, and on any block that switches language.

```html
<html lang="tr">
```

## Rules

- Large headings are tight: negative tracking and a line height close to 1. Body text is relaxed at 1.6.
- Headings use `text-wrap: balance` so short titles do not leave a single word on the last line.
- Keep reading width at or below `--mrd-prose` (720px).
- Use the three text tones for hierarchy: `--mrd-ink` for headings, `--mrd-body` for text, `--mrd-muted` for meta.

## Font stacks

```css
--mrd-font-sans: "Archivo", ui-sans-serif, system-ui, -apple-system, "Segoe UI", sans-serif;
--mrd-font-mono: "Chivo Mono", ui-monospace, SFMono-Regular, Menlo, monospace;
--mrd-font-display: var(--mrd-font-sans);
```

`--mrd-font-display` is the face of the display heading. It points at the sans by default; set it to change the hero face without touching the rest of the interface.

## What ships

Each family is two woff2 files, a latin and a latin-ext subset, and the browser downloads the second one only when the page uses a character from it. The dotless ı is in the latin file; ğ, ş, İ and ₺ are in latin-ext. The files are cut down to the axes Merid uses, weight 400 to 600 and, for Archivo, width 100% to 125%, which brings all four to 120 KB. The Geist pair they replaced was 141 KB. Browsers only fetch a face that is actually used, so if you set your own `--mrd-font-sans` and `--mrd-font-mono`, none of these files is requested.
