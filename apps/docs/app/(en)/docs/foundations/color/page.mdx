# Color

Merid's palette is one accent and a set of ink-tinted neutrals. The default accent is map magenta, the colour nautical and aeronautical charts keep for the information that matters most. It marks interaction and selection; the neutrals carry everything else. Status colours appear as soft tints with strong text, never as large saturated fills.

## Rules

- Use the accent for things people can act on, and for the current selection. Do not use it for decoration or emphasis.
- Separate regions with `--mrd-tray` before reaching for a line. Hairlines are 1px `--mrd-line`; the ink rule `--mrd-rule` is kept for closing tables.
- Build hierarchy with the three text tones (`ink`, `body`, `muted`) and weight, not with colour.
- A page has at most one filled colour block.

Danger is a vermilion pulled towards orange rather than a crimson. Next to a magenta accent, a crimson error would read as a link or a selection; the shift keeps the two apart.

Brass is the one preset that also moves a status colour. Its accent is an amber, so under `data-accent="brass"` the warning tone shifts to orange (`#9e4500` light, `#f9a870` dark) and a warning badge never reads as an accent badge.

The numbers come from `packages/react/scripts/contrast.mjs`, which prints every pair and exits with an error below 4.5:1. A test in the package fails if the script and the stylesheet ever disagree about a colour.

## Using colour in your own components

```css
.notice {
  background: var(--mrd-warning-soft);
  color: var(--mrd-warning-strong);
  border-radius: var(--mrd-radius-lg);
}
```
