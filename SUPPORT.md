# Getting help

- **Documentation** — start with the docs site; the search (⌘K / Ctrl K) covers every page and section.
- **Questions and ideas** — ask in [GitHub Discussions](https://github.com/ahmetcantryk/merid/discussions). Include a short code sample and your versions.
- **Bugs** — open a [bug report](https://github.com/ahmetcantryk/merid/issues/new/choose) with a minimal reproduction.
- **Security issues** — follow [SECURITY.md](SECURITY.md). Never report them publicly.

Merid is maintained in spare time. There is no paid support and no guaranteed response time, but well-described issues with a reproduction are usually answered within a week.
